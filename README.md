# InvisiHome AI Dashboard

**InvisiHome** is an AI-powered housing inclusion dashboard that integrates a Machine Learning model to analyze and visualize housing data for sustainable development.  
Built with **React**, **TypeScript**, and **Tailwind CSS**, and deployed on **Netlify**.

---

## 🌐 Live Demo

Check out the dashboard here: [InvisiHome](https://inspiring-licorice-344bd2.netlify.app)

---

## 🛠️ Technologies Used

- **React** – Frontend library for building interactive UIs  
- **TypeScript** – Strongly typed JavaScript for reliability  
- **Tailwind CSS** – Utility-first CSS framework for styling  
- **Vite** – Development and build tool  
- **Netlify** – Deployment and hosting  
- **PostCSS** – CSS processing  
- **ESLint** – Code linting for consistent coding style
